# 01-03: Create synthetic test framework and xSIM infrastructure

**Goal:** Establish testing infrastructure for module development using xSIM simulation and synthetic audio generation.

## Success Criteria

- pytest-based test framework runs synthetic audio scenarios
- xSIM simulation executes firmware without hardware
- Test data organized per-module in `tests/data/` directories
- Conftest.py configures xSIM simulation fixtures

## Implementation Steps

### 1. Create test directory structure

```
satellite-xmos-firmware/
tests/
    conftest.py              # xSIM fixture configuration
    data/                     # Shared test data
    synthetic/
        __init__.py
        test_audio_generation.py  # pyroomacoustics scenarios
    xsim/
        __init__.py
        test_firmware_simulation.py  # xSIM execution tests
```

### 2. Create pytest conftest.py with xSIM fixtures

- Create `satellite-xmos-firmware/tests/conftest.py`:

```python
import pytest
import Pyxsim as px

@pytest.fixture
def xsim_runner():
    """Provides xSIM simulation runner for firmware"""
    def _run(binary_path, xscope_file=None):
        return px.run_simulation(
            binary_path,
            xscope_file=xscope_file,
            timeout=30  # seconds
        )
    return _run
```

### 3. Create synthetic audio generation module

- Create `satellite-xmos-firmware/tests/synthetic/test_audio_generation.py`:
  - Use pyroomacoustics to simulate room acoustics
  - Generate scenarios: single speaker at various angles, multi-source, ambient noise
  - Output format: 16kHz PCM, 4-channel for mic array input
  - Store generated audio in `tests/data/synthetic/`

### 4. Create xSIM simulation tests

- Create `satellite-xmos-firmware/tests/xsim/test_firmware_simulation.py`:
  - Test firmware boots and runs for N frames
  - Test xSIM trace extraction with `-t` flag
  - Verify audio pipeline processes all 4 channels
  - Validate inter-tile communication (port 7) functionality

### 5. Configure xSIM trace format

- Define trace points in firmware for key events:
  - PDM capture start/end
  - Audio pipeline frame processing
  - DOA module updates (for Phase 2)
- Use xscope logging infrastructure for trace output

### 6. Create pytest configuration

- Create `satellite-xmos-firmware/tests/pytest.ini`:

```ini
[pytest]
markers =
    xsim: Tests requiring xSIM simulation
    synthetic: Tests using synthetic audio data
    hardware: Tests requiring actual hardware
testpaths = synthetic xsim
```

## Verification

```bash
# Install dependencies (add to requirements.txt if needed)
pip install pyroomacoustics pytest pytest-cov

# Run synthetic audio generation tests
pytest satellite-xmos-firmware/tests/synthetic/ -v

# Run xSIM simulation tests
pytest satellite-xmos-firmware/tests/xsim/ -v

# Run all Phase 1 tests
pytest satellite-xmos-firmware/tests/ -v
```

## Notes

- xSIM simulation requires XTC Tools installation and proper environment setup
- pyroomacoustics simulates room with configurable reflection, absorption
- Test data stored in per-module `tests/data/` for module portability
- xSIM traces integrated as pytest artifacts for CI/CD pipelines
