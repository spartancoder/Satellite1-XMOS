# 01-02: Enable 4-mic PDM capture and verify audio output

**Goal:** Enable capture from all 4 microphones on Satellite1 hardware and verify audio output.

## Success Criteria

- PDM capture configured for 4 microphones (channels 0, 1, 4, 5)
- Firmware captures audio from all 4 microphones
- Audio output to I2S includes all 4 channels (via TDM mode)
- Build produces no new warnings

## Implementation Steps

### 1. Update mic array configuration in SATELLITE1.cmake

- Modify `satellite-xmos-firmware/bsp_config/SATELLITE1/SATELLITE1.cmake`:

```cmake
# Mic mapping for 4 mics:
# North: 0 (pin 0 falling edge)
# South: 1 (pin 1 falling edge)
# East:  4 (pin 0 rising edge)
# West:  5 (pin 1 rising edge)
set(MIC_MAPPING "0, 1, 4, 5")

# Update mic count
target_compile_definitions(fph_ffva_board_support_satellite1
    INTERFACE
        ...
        MIC_ARRAY_CONFIG_MIC_INPUT=8
        MIC_ARRAY_CONFIG_MIC_COUNT=4  # Changed from 2
        MIC_ARRAY_CONFIG_INPUT_MAPPING={${MIC_MAPPING}}
        ...
)
```

### 2. Enable TDM mode for 4-channel I2S output

- Update `satellite-xmos-firmware/src/app_conf.h`:

```c
#ifndef appconfI2S_TDM_ENABLED
#define appconfI2S_TDM_ENABLED     1  // Enable TDM for 4-channel output
#endif
```

### 3. Update beamformer pipeline configuration

- Modify `satellite-xmos-firmware/audio_pipelines/reference/beamformer/audio_pipeline_dsp.h`:

```c
/* Pipeline config */
#define AP_MAX_Y_CHANNELS (4)  // Changed from 2 for 4 mics
```

### 4. Verify and build

- Build `satellite1_firmware_beamformer`
- Check for configuration conflicts or new warnings
- Validate that all audio pipeline stages (AEC, IC, VNR, NS, AGC) handle 4-channel input

### 5. Audio verification (hardware)

- Flash firmware to Satellite1 hardware
- Use logic analyzer or audio capture to verify 4 PDM channels active
- Verify I2S TDM output contains 4 microphone channels

## Verification

```bash
# Build firmware
cmake -B build -DUSE_DEV_TRACKING=ON --toolchain xmos_cmake_toolchain/xs3a.cmake
cd build
make satellite1_firmware_beamformer
make create_upgrade_img_satellite1_firmware_beamformer
```

## Notes

- Current hardware has 4 mics but firmware uses only 2 (East/West: pins 4,5)
- North (pin 0) and South (pin 1) mics are being enabled
- TDM mode required to output 4 channels over single I2S line
- Audio pipeline stages already support configurable channel count via `AP_MAX_Y_CHANNELS`
